CORE API viewer
createSomakine(container, options)
Create a viewer with a verified data pack and host callbacks.
setLocale(locale) · setLayer(type | null)
Switch labels and show one structure type or restore all layers.
focusStructure(id) · focusRegion(id)
Isolate a canonical structure or focus a named anatomical region.
setVisible(ids) · showBody() · reset()
Control the visible set and return to the complete framed model.
dispose()
Release controls, listeners, renderer, and loaded resources.

options accepts the data pack, accessibility label, view vectors, abort signal, asset resolver, callbacks, and canvas background. Public types include ViewerSelection, ViewerState, ViewerPhase, CreateSomakineOptions, SomakineViewer, ViewFit, AssetResolver, and Asset. Utilities: calculateViewFit · normalizeViewVector · createPrimitiveObject · findGltfNode · defaultAssetResolver · verifyAssetBytes · assertSelfContainedGlb · disposeObject3D.
