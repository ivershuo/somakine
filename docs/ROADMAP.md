# Roadmap

## Alpha 0.1

- core schema, validation, catalog, and CLI;
- synthetic musculoskeletal pack;
- framework-neutral Three.js viewer;
- BodyParts3D adapter contract;
- developer data-extension contract and deterministic pack composition;
- vanilla example and package conformance checks.

## Alpha 0.2

- deterministic BodyParts3D source pipeline;
- canonical whole-body bone pack;
- real GLB asset budgets, LODs, and provenance reports;
- browser automation for accessibility and GPU lifecycle journeys.

## Beta

- reviewed major-muscle coverage;
- second source-adapter fixture;
- fitness and rehabilitation education examples;
- public package publishing and migration policy.

## Stable 1.0

Requires two independent consumers, an exercised schema migration, expert
anatomy review, asset-license review, and measured browser budgets.
